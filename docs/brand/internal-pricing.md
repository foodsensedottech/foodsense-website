# Internal pricing (never publish)

**Do not put rates, formulas, or commission tiers on foodsense.tech, in Contentful, or in public metadata.**

Source: Brand OS PDF 05. Website commercial shape stays: initiation fee + monthly fee sized to the work. This file is for scoping and proposals only.

## Philosophy

- Value over hours. Price the complexity and the outcome.
- Transparency. The client always knows what they are paying for.
- Phased investment. Start small, prove it, expand.
- US vs LATAM rate differential is real (PDF: US 20–40% higher). Do not print that on the site.

## What drives scope

Number of markets, number of vendors, technical complexity, duration/depth, advising vs managing execution.

## Calculators (from Brand OS PDF)

### Advisory retainer

`Monthly fee = base hourly rate × expected hours/month × complexity multiplier`

| Input | Range / default |
| --- | --- |
| Base hourly | $175–$300/hr (target annual / 1,200 billable hours) |
| Hours / month | 10–20 |
| Complexity | 1.0x single market · 1.25x multi-market · 1.5x multi + active escalations |
| Burst overage | 1.25x base if hours exceed cap by 20%+ |
| Minimum | 3 months |
| Annual discount | 10–15% for 12-month commit |

### Project-based

`Fee = (estimated hours × blended rate) × risk buffer × value adjustment`

| Input | Range / default |
| --- | --- |
| Blended rate | $200–$300/hr |
| Risk buffer | 1.15x well-defined · 1.25x ambiguous · 1.4x high-unknown |
| Value adjustment | 10–20% of value created |
| Milestones | 30% kickoff / 40% pilot / 30% completion |
| Change order | 1.25x base |

### Fractional / embedded

`Monthly = daily rate × days/week × 4.33 × seniority premium`

| Input | Range / default |
| --- | --- |
| Daily rate | $1,500–$2,200 (hourly × 8, discounted 10–15%) |
| Days / week | 3 advisory · 4 + team lead · 5 full ownership |
| Seniority | 1.0x advising · 1.2x decision authority |
| Duration discount | 5–10% at 6+ months |
| Max as “bridge” | 6–12 months |
| Exit | 30 days notice |

### Workshops & assessments

`Fee = (prep days × prep rate) + (delivery days × delivery rate) + deliverable fee`

| Input | Range / default |
| --- | --- |
| Prep | 1.5–2× delivery days |
| Prep rate | $1,500–$2,000/day |
| Delivery | 1–5 days at 1.3–1.5× base ($2,000–$3,000/day) |
| Deliverable | $5,000–$15,000 |
| Virtual | 10% reduction |
| Travel | at cost |

### Blackthorn referral (internal)

| Tier | Involvement | Rate |
| --- | --- | --- |
| 1 | Intro only | 10% |
| 2 | Intro + scoping | 15% |
| 3 | Intro + scoping + oversight | 20% |
| Recurring | First 12 months | same tier |

## Universal inputs

- Utilization target: 25–30 billable hours/week is realistic.
- Minimum engagement: under $10K may not be worth it.
- Overhead buffer: 15% (subcontractors, tools, travel, insurance).
